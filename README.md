## Apps

### Shoootz

Avalonia-Desktopanwendung zur Verwaltung von Sektionsliga Wettkämpfen.

### Shoootz.Bridge.TCP

Diese App empfängt UDP-Broadcast Pakete im lokalen Netzwerk und leitet sie an verbundene TCP-Clients weiter.
Läuft auf dem Server-PC, damit Shoootz-Clients außerhalb der Broadcast-Reichweite die Schüsse trotzdem zuverlässig empfangen.
